# Notes 1 - Arrays & Linked Lists
## Arrays
- Arrays have fixed lengths
- DIRECT element access O(1) time complexity
- Creating an array in java: int[] x = new int[2]; Where 2 is the array size
- Static structure

### Operations on Arrays
- Access any index in constant time
- Deleting and inserting elements from an array is costly and time consuming

## Linked Lists
- A singly linked list is a sequence of nodes
- Each node stores an element and a pointer to the new node in the linked list
- Nodes are not stored adjacently
- Easy to insert at the tail, but costly to delete the last node
- Dynamic structure

## Doubly Linked List
- Similar to the singly linked list, but also with a pointer to previous
- Easy to insert at the tail, and easy to delete the last node since we know the node before the last node
- Take up more memory than singly linked lists
- Dynamic structure
